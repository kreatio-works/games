# games

ブラウザですぐ遊べる小さなゲーム集です。インストール不要・無料。

**▶ https://kreatio-works.github.io/games/**

| ゲーム | 内容 |
|---|---|
| [JOSUSHI](https://kreatio-works.github.io/games/josushi/) | 宇宙の回転寿司で、日本語の数え方（助数詞）を当てるゲーム。CPU対戦・タイムアタック。日英併記 |

## 構成

- `index.html` … ゲーム一覧（トップページ）
- `<ゲーム名>/index.html` … 各ゲーム（1ファイル完結）

ゲームを増やすときは、フォルダを足してトップページにカードを1枚追加します。
